# 20260919丨果实之心丨入口独立开关修复
> 更新于 2026-09-19 · 状态：完成，待真实用户验收

## 结论
Git 发布版已更新到 `20260919.13`。快捷栏与悬浮猫咪的开关流程已彻底拆开，切换任一入口不再隐藏另一个；当前加载的 V6.13 预设已同步 Git/本地两份脚本，预设正文未改。

## 关键决策
- 主脚本在检测到外部 ECoT 模块仍使用旧四项默认值时，调用 `setEndTags` 自动补上第五项；其他自定义标签列表保持原样。
- 更新 `src/fruit-heart.template.js`、`vendor/js-sha256.js` 后统一运行 `build.mjs`，由 `release-notes.json` 同时生成 release、校验信息和更新页记录。
- 每个脚本实例使用独立节点标记和 jQuery 命名空间；pagehide/unload 只销毁本实例，避免旧实例误删新实例。
- 快捷栏兜底入口必须使用酒馆原生的 `div.qr--button` 结构；使用 `<button>` 会触发主题/浏览器原生灰底，产生截图中的异常外观。
- 更新提示只在自动检查发现远端版本更高时出现；网络失败时不占标题栏位置，设置里的更新页仍可手动检查。
- 更新页的状态、下载说明和版本记录分开排版；下载完成后提示刷新酒馆，缓存配额错误改成可读的中文提示。
- 更新写入前先删除同名旧脚本缓存；Git 加载器也使用相同策略，避免旧缓存与新脚本同时占用配额。
- 快捷栏和悬浮猫咪是两个独立入口；快捷栏识别失败时不再强行显示悬浮猫咪，避免“关闭悬浮球仍出现”的回归。
- 快捷栏识别保留 `🍎果实之心` 与旧版 `🍎 果实之心` 两个别名，更新后已有 Quick Reply 仍能打开面板。
- 兜底节点必须挂在实际 `.qr--buttons` 容器，且保留 `menu_button`、隐藏图标、标签和展开器四段结构；直接挂 `#qr--bar` 会掉到下一行并显示成异样文字按钮。
- `bindEntry()` 不能在 `entryBar === false` 时提前返回；悬浮猫咪显示和随机小剧场绑定都在快捷栏分支之外执行。

## 坑
- 仅修改主脚本的三项 fallback 不够：预设里的 ECoT 模块可能已经返回旧四项，因此需要运行时识别旧默认并迁移。
- 宽屏 `columns:2` 会把主面板变成横向多栏，改为单栏纵向滚动后才不会丢失后续设置。
