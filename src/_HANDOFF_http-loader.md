- 真实非安全 HTTP origin 中复现：release.json 和脚本下载成功，crypto.subtle 为 undefined，digest 调用抛错，被旧入口一律提示“检查网络”。用户朋友是否正是同一原因尚缺访问地址或原始错误。

- 浏览器通过非安全 origin 冷启动、无网缓存启动、更新检查、坏校验值拒绝及网络阶段错误提示测试；原 13 项模型分组测试通过。

## 关键决策
- 旧入口执行校验前已经失败，远程发布无法修复已内嵌的入口。install 下提供独立酒馆助手脚本 JSON，用户关闭旧 Git 脚本后导入并开启；不得同时启用两个 Git 入口。
- 本轮不修改用户预设或 settings.json。导入文件仅含新的脚本入口，按当前酒馆助手 Script schema 生成，不包含 ECoT 或预设正文。
- 所有环境统一使用纯 JS 校验，没有跳过校验或降级通道。CommonJS 包封装在局部作用域，避免污染页面 sha256 等全局变量。
- 错误消息显示失败阶段：连接发布信息、下载、校验、执行。开代理不代表 raw.githubusercontent.com 请求一定成功，朋友若修复后仍失败需按新的具体错误继续诊断。
