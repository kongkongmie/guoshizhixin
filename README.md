# 20260918丨果实之心丨统一面板脚本

果实 V6 系列的果实之心面板脚本。仓库不包含预设正文、聊天或运行配置。

`loader.js` 放入预设原有的果实之心主脚本 content；ECoT 独立脚本保持原样。各预设共用这一入口。

首次加载从 GitHub 下载发布版本，校验后缓存到浏览器。之后先运行本地缓存，后台检查并下载更新，下一次刷新生效。首次加载需要能访问 raw.githubusercontent.com；没有缓存且网络不可用时会明确报错。不能承诺所有地区的首次加载速度。

`release.json` 指向 `releases/<版本>/fruit-heart.js` 并记录 SHA-256。每次发布创建新版本目录，不能修改已经发布的版本文件，再更新 release.json。开发代码不要直接作为发布入口。

当前修复：

- 面板分区保存到 `extensions.fruitHeartSections`；首次同步从现有柏宝箱分区导入，此后独立维护。用户点击同步才更新这份面板元数据，不改条目正文、开关及排列。
- 识别“需求字数2200-2500字”和“需2200-2500字”；用户改字数时只替换数字。
- 面板内部隔离宿主文字阴影。
- 底部四项导航，非全屏点击外部关闭，顶部关闭按钮保留。

发布验证必须包括同步幂等、用户主动调整字数时的正文差异、三皮肤主题隔离，以及加载器首次下载、缓存启动和更新行为。真实用户美化主题仍需用户现场确认。

## 模型联动与更新页（20260918.3）

设置中的“跟随连接模型”默认开启，按实际模型名识别 Gemini Flash / Pro、Claude、DeepSeek，使用当前预设已有标签。面板关闭时仍可联动；连接名稳定约一至两秒后切换。未知或有歧义的模型保持原状，同一连接下手动选择模型组不会被反复覆盖。开关存于本浏览器，不写入预设正文。

设置 → 查看更新记录，进入独立更新页。离线可读内置历史；检查更新后可下载新版并校验，刷新后由 Git 入口运行。使用本地测试版时需要手动切回 Git 版。更新失败不会覆盖现有缓存。

## 维护与发布

源文件在 `src/`，版本和更新记录由 `release-notes.json` 统一管理。先运行 `node --test tests/model-link.test.mjs` 与浏览器交互验证，再执行 `node build.mjs`。构建会输出不可变版本目录、嵌入版本号和日志、计算清单校验值；已有版本内容不同会拒绝覆盖。

一般先更新本地测试副本，收到测试通过及推送授权后发布；若用户明确要求直接改 Git，则按该次授权发布。提交历史可追溯，既有 release 文件必须保留。

20260918.4：`GEMINI 3.7F`、`GEMINI 3.8F`、`GEMINI FLASH` 等标签统一显示为 Gemini Flash，忽略大小写。分组选择匹配各条目的原始标签，保留各自开关记忆；Flash 与 Pro 不混合。

20260918.5 修复普通 HTTP 酒馆的脚本加载和更新校验。旧加载入口错误依赖仅在安全上下文可用的 Web Crypto；使用旧入口的用户需先关闭旧 Git 脚本，再导入 `install/20260918丨果实之心丨Git加载修复.json` 并开启。仅更新远程版本无法自修旧入口。校验库 js-sha256 0.11.1 内置在脚本中，不额外访问第三方 CDN；许可证见 vendor。

## 本地开发：NSFW 关键词联动

运行 `node --test tests/*.test.mjs`，再运行 `node build.mjs --local`，生成 `dev/fruit-heart-local.json`。先关闭原果实之心脚本，再向酒馆助手导入并启用此测试版；本地版内嵌代码，不自动下载上游正式版。此命令不修改已发布版本、release.json 或原安装文件。

设置 → NSFW 关键词联动：启用后与首页现有 NSFW 总开关控制同一个条目，保留分区细项。内置用户提供的 26 个去重关键词，支持英文/中文逗号、顿号、分号和换行；可编辑并补入默认词。首次升级旧联动规则时合并默认词与已有词，保留启用状态和轮数，原手选条目配置不再参与控制。

默认关闭，默认连续 2 轮未命中后关闭，也可选 1 轮。输入在生成前检测，完整回复在结束后检测并供下轮生效；任一处命中即开启并重置计数，只有完整一轮都未命中才累计。重新生成、续写、自动触发、切换回复页、中断生成不累计。聊天切换、保存规则、手动切换 NSFW 总开关和脚本重载会清零计数。

规则按预设保存在本浏览器，自动切换只写当前使用中的预设，不直接覆盖已保存预设；其他手动保存操作仍可能保存当前状态。停用联动或卸载脚本保留当前总开关状态。文本匹配忽略英文大小写，按字面包含，不理解否定或引用，也不读取独立 reasoning 字段。规则未保存时有提示，切换页面保留当前实例的草稿；重载脚本前仍需点击保存。

审查与验证见 [维护检查记录](docs/review-2026-09-20.md)。

详见 [源码结构与维护入口](docs/architecture.md)，包含模块职责、共享接口、执行顺序与验证命令。最终仍生成单个酒馆助手导入 JSON，不增加运行依赖。
