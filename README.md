# 20260918丨果实之心丨统一面板脚本

果实 V6 系列的果实之心面板脚本。仓库不包含预设正文、聊天或运行配置。

`loader.js` 放入预设原有的果实之心主脚本 content；ECoT 独立脚本保持原样。各预设共用这一入口。

首次加载从 GitHub 下载发布版本，校验后缓存到浏览器。之后先运行本地缓存，后台检查并下载更新，下一次刷新生效。首次加载需要能访问 raw.githubusercontent.com；没有缓存且网络不可用时会明确报错。不能承诺所有地区的首次加载速度。

`release.json` 指向 `releases/<版本>/fruit-heart.js` 并记录 SHA-256。每次发布创建新版本目录，不能修改已经发布的版本文件，再更新 release.json。开发代码不要直接作为发布入口。

当前修复：

- 面板分区保存到 `extensions.fruitHeartSections`；首次同步从现有柏宝箱分区导入，此后独立维护。用户点击同步才更新这份面板元数据，不改条目正文、开关及排列。
- 识别“需求字数2200-2500字”和“需2200-2500字”；用户改字数时只替换数字。
- 面板内部隔离宿主文字阴影。
- 底部四项导航，非全屏点击外部关闭，顶部关闭按钮保留。

发布验证必须包括同步幂等、用户主动调整字数时的正文差异、三皮肤主题隔离，以及加载器首次下载、缓存启动和更新行为。真实用户美化主题仍需用户现场确认。
